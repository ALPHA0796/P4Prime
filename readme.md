# 实验过程

### 初始化

- 先将本文件夹得所有文件拷贝到一个空目录下，务必保持文件之间的相对位置不改变
- 然后在本文件夹下运行如下命令：
`sudo python3 FatTree_4.py`
- 在命令行中等待拓扑构建完成，完成后会有mininet的交互命令行
- 在mininet命令行内输入：
`xterm h1`
这样会弹出h1的命令行
- 接下来分别阐述**使用p4prime**和**不使用p4prime**的步骤

### 使用p4prime
- 在该文件夹下重新开一个终端，并输入如下指令：
`sudo python3 test.py`
- 在发现程序打印了主机上的所有端口后回到h1的命令行窗口，输入：
`./topo/FatTree6/send.py --n [包的发送个数] --ip 10.0.8.16 --m tag --t 0.1`

- 等待h1的命令行能够重新输入，能够重新输入的时候意味着实验结束
- 回到刚刚执行`test.py`的命令行窗口，按下ctrl+c,等待2秒，再按一次ctrl+c，就会在当前文件下产生一个res.csv文件

### 不使用p4prime
- 在该文件夹下重新开一个终端，并输入如下指令：
`sudo python3 test.py --o 1`
- 在发现程序打印了主机上的所有端口后回到h1的命令行窗口，输入：
`./topo/FatTree6/send.py --n [包的发送个数] --ip 10.0.8.16 --t 0.1`

- 等待h1的命令行能够重新输入，能够重新输入的时候意味着实验结束
- 回到刚刚执行`test.py`的命令行窗口，按下ctrl+c,等待2秒，再按一次ctrl+c，就会在当前文件下产生一个res.csv文件

### 收集数据并计算平均值
- res.csv内保存了上次实验的所有数据，如要保存，请复制到另一个文件中
- 在当前文件夹下使用如下命令计算res.csv内数据的均值：
`sudo python3 mean.py`

### res.csv数据存储格式
- 左边是包的发送编号，右边是具体的数据
